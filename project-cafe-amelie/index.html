Cafe Amelie

Café Amélie is a café brand created as a personal project to explore a warm, modern web experience for a small hospitality business.

Visit website↗︎

Goal

Design a simple, inviting website that:

Communicates the café’s atmosphere and values

Clearly presents menu, location and opening hours

Works smoothly on both desktop and mobile

Offers Light and Dark mode

Target Audience

Locals, creatives, and remote workers looking for a cosy café experience.

My Role

UX/UI Design · Visual Direction · Framer Development

Defined a minimal site structure (home, menu, about, reserve, book private event, contact)

Design Choices

Warm color palette to evoke friendliness and comfort

Clean typography for easy reading

Fun animations and Interactions

Outcome

A responsive website concept designed to showcase branding, layout and interaction skills for hospitality projects.
